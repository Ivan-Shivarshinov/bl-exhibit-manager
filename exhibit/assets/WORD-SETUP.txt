Панель Word — необязательное дополнение

Для обычной загрузки DOCX/PDF и сборки комплекта эта настройка не нужна.
Нужен настольный Microsoft Word с поддержкой WordApi 1.5.
Python, Node и исходники для подключения из готового приложения не требуются.

1. ПОДГОТОВКА
В верхней строке приложения нажмите «Помощь и настройка».
В блоке «Панель Word» нажмите «Подготовить подключение Word».
Если порт занят, выберите другой номер, например 8770, и повторите.
Сертификат и ключ создаются только на вашем компьютере. При повторном
открытии настройки не заменяются. Приложение должно оставаться запущенным.

2. ДОВЕРИЕ СЕРТИФИКАТУ
Для созданного приложением сертификата нажмите «Скачать сертификат».
Сверьте имя BL Exhibit Manager localhost, срок и SHA-256 с данными в приложении.
Системное доверие подтверждаете вы; приложение не устанавливает его скрытно.
Можно отказаться и продолжить работу без панели. Не отключайте проверку HTTPS.

Windows:
Откройте скачанный BL-Exhibit-localhost.crt → «Установить сертификат» →
«Текущий пользователь» → «Поместить все сертификаты в следующее хранилище» →
«Обзор» → «Доверенные корневые центры сертификации» → «Готово».
Подтвердите установку именно этого локального сертификата.
Не оставляйте автоматический выбор хранилища: сертификат может попасть
в «Промежуточные центры сертификации», и браузер продолжит показывать
ERR_CERT_AUTHORITY_INVALID. В таком случае повторно установите тот же файл,
явно выбрав «Доверенные корневые центры сертификации». Новый сертификат не нужен.

Mac:
Откройте скачанный сертификат в «Связке ключей», добавьте в связку «Вход».
Найдите BL Exhibit Manager localhost, откройте двойным щелчком → «Доверие».
Для Secure Sockets Layer (SSL) выберите «Всегда доверять», закройте окно
и подтвердите изменение паролем, если система его запросит.

Для прежнего подключения со своим сертификатом используйте инструкцию
его поставщика. Не устанавливайте произвольный сертификат сайта как корневой.

Вернитесь в приложение → «Проверить HTTPS». Дополнительно откройте адрес
панели из блока подключения в браузере (на Mac — Safari): предупреждения
о сертификате быть не должно. Проверка приложения не заменяет проверку Word.
Если проверка не проходит, убедитесь, что доверие установлено для нужного
пользователя и сертификат не истёк. На Mac runtime и Word могут использовать
разные хранилища доверия; Safari проверяет системное доверие.

3. УСТАНОВКА ПАНЕЛИ В WORD
В приложении нажмите «Скачать манифест Word».
В каталог надстроек копируется только BLExhibitManager.Word.xml, не ключи.
Это локальное подключение для настольного Word, не публикация в магазине.

Windows:
Создайте отдельную папку для манифеста. В её свойствах → «Доступ» →
«Общий доступ» предоставьте доступ своей учётной записи и скопируйте
показанный сетевой путь. Не размещайте в этой папке документы или ключи.
В Word: «Файл» → «Параметры» → «Центр управления безопасностью» →
«Параметры центра управления безопасностью» → «Надёжные каталоги надстроек».
Добавьте сетевой путь, отметьте «Показывать в меню», сохраните.
Перезапустите Word → «Главная» → «Надстройки» → «Дополнительно» →
«Общая папка». Выберите BL Exhibit Manager → «Добавить».
Названия пунктов могут немного отличаться в вашей версии Office.
Microsoft описывает этот каталог как способ локального тестирования;
в управляемой организации установка может потребовать участия администратора.
https://learn.microsoft.com/office/dev/add-ins/testing/create-a-network-shared-folder-catalog-for-task-pane-and-content-add-ins

Mac:
В Finder нажмите Cmd+Shift+G и откройте
~/Library/Containers/com.microsoft.Word/Data/Documents/
Создайте в ней папку wef, если её нет. Скопируйте туда манифест XML.
Перезапустите Word, откройте документ → «Главная» → «Надстройки» →
BL Exhibit Manager.
https://learn.microsoft.com/office/dev/add-ins/testing/sideload-an-office-add-in-on-mac

4. РАБОТА
Выберите проект в панели. Поставьте курсор в основной текст документа,
выберите приложение и нажмите «Создать сноску в Word».
После изменения названий или номеров нажмите «Проверить ссылки», затем
«Применить выбранные изменения». Сохраните DOCX и передайте его в приложение.

ОБНОВЛЕНИЕ
Остановите прежнее приложение через Stop и запустите новое.
Действующие настройки и сертификат сохраняются; повторное доверие не требуется.
При переносе проекта на другой компьютер подключение Word настраивается заново.
Секретный ключ нельзя пересылать, прикладывать к отчётам или публиковать.
