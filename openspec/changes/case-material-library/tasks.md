## Наблюдаемый критерий завершения

Пользователь сохраняет материал с подтверждённым переводом в библиотеку, находит и добавляет его в две подачи с разными номерами без повторного перевода. После сохранения v2 видит отличия, обновляет только одну подачу и может оставить/выбрать v1 в другой. Прежние ZIP и исходники неизменны. Обе подачи работают без библиотеки; архив библиотеки переносит все версии между Windows и Mac. Принятые расширения дополнительно проходят свои проверки. Код, автоматические проверки, реальный интерфейс/Word, подтверждение пользователя и факт выпуска отмечаются раздельно; ответы коллег не являются формальным условием закрытия.
