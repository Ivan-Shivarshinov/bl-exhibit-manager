# Независимая проверка PR #6 — исправления перед 0.5.0

Прежняя готовность отозвана; изменение возвращено из архива. Задачи 5.3–5.5, 7.5, 8.2 и 8.5 открыты до новых доказательств. PR не объединять, Release не публиковать.

## 1. Местное обозначение и готовый PDF

На исходном кандидате `17bc4bc` воспроизведено: библиотека Exhibit → импорт Annex 12 → замена перевода → обновление превращает идентификатор в Exhibit 12 при имени Annex 12.pdf. Тест до исправления завершился ошибкой. Исправлено трёхстороннее сравнение: designation исключён из переносимого библиотечного оформления и нормализован к местному эффективному обозначению. ID, префикс, номер, имя/режим имени, папка и варианты упоминаний не заменяются. Смена перевода снимает проверку результата; неизменённые ссылки не требуют повторной проверки. Смена названия по-прежнему снимает проверку ссылок.

Адресная регрессия: исходный Exhibit, A Annex 3/v1, B Annex 12/v1 → v2 → v1. Проверяется текст Annex 12 на каждой странице экспортированного PDF, отсутствие Exhibit 12, перевод, назначенные поля, неизменные A и старые ZIP/исходники. Отдельный тест — пустое местное обозначение, префикс AU-LA, ручное имя/папка и явный выбор библиотечного оформления. Нативный API-сценарий проверяет четыре страницы обновлённого PDF и три страницы возврата.

## 2. Совпадения всей истории

На `17bc4bc` загрузка и сохранение прежнего оригинала/перевода после v2 дали ноль совпадений. Исправлено: индекс читает манифесты всех версий, включая скрытые материалы; каталог, фильтр и текущая страница не ограничивают поиск. Полное совпадение определяется по хешам содержания ролей; производный готовый PDF исключён, когда есть оригинал. Одинаковый оригинал с иным переводом/составом показан отдельно. Описания совпадений хранятся один раз для общего массового списка, без чтения всех PDF при поиске. Для 100 строк с 3000 совпадений каждой предварительный состав — 13.5 МБ, читается в существующем лимите; UI показывает совпадения порциями.

Автоматические тесты покрывают прямую загрузку и сохранение из подачи, v1 после v2, скрытый материал, одинаковые байты под другим именем, другой перевод, неверный/устаревший выбор, отмену и безопасный повтор. Использование существующего возвращает точную версию; новая версия и отдельный материал требуют явного решения.

## 3. Действия с найденным материалом

Прежнее сообщение предлагало использовать неназванный материал. Теперь каждая строка показывает название и номер совпавшей версии, признаки скрытого материала/текущей загрузки и прямой просмотр. Кнопки: использовать существующий материал, сохранить новую версию этого материала, сохранить отдельный материал. При отличающемся переводе использование как полного совпадения недоступно; выбор новой версии или отдельного материала обязателен, если целевой материал заранее не выбран. Есть явное общее сохранение отдельно; запись блокируется до решений. Много совпадений показываются порциями.

Проверка интерфейса — настоящие страницы Chromium через Playwright, без управления рабочим столом. Синтетическая библиотека 100 карточек: совпавшая v1/v2 карточка вне первой страницы; просмотр v1, использование без копии, новая версия, отдельный материал, совпадение между строками загрузки и сохранение из подачи. Ширины 1440/760/390, ошибки JavaScript отсутствуют. JSON/снимки локально: `output/qa-v050-review/`. Также пройден прежний браузерный сценарий 100 PDF/массовый импорт/фильтры/конфликты. Browser plugin не доступен; использован установленный Playwright.
