## Итоговый CI и пакеты

[CI 37953879339](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/actions/runs/37953879339) (push) и [CI 37953886268](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/actions/runs/37953886268) (PR) завершились успешно: три нативных пакета и три задания взаимного обмена. Каждый нативный запуск прошёл 270 Python-тестов, 23 JS-теста, сборку интерфейса, запуск EXE/app, независимые проекты/ZIP, библиотечный сквозной сценарий, нагрузку и браузерные действия. Новая версия запускается после переноса папки приложения, проекты и прежние ZIP сохраняются.

Пакеты скачаны из push-CI в `output/release-v050-final/`. Проверены SHA-256, версия/архитектура/коммит в build-info и актуальная инструкция. `SHA256SUMS.txt`, `VERIFICATION.json` и `RELEASE-NOTES.md` лежат рядом. Для каждого нативного комплекта отдельно проверен текст **Annex 3 / Annex 12 на всех трёх страницах PDF**, а не только номер в метаданных.

Взаимный обмен: на каждой из трёх платформ восстановлены архивы библиотек и подач с других нативных сборок, сохранность исходников/истории проверена побайтово и комплект собран заново. Дополнительно восстановлены архивы, созданные **кодом опубликованных тегов v0.3.0 и v0.4.0** (`scripts/generate_legacy_archives.py`). Schema 1 не переписывается при открытии; первый библиотечный импорт создаёт проверенный архив и только затем публикует schema 2.

## Сценарии и сохранность

- `test_library.py` / `test_library_api.py`: схемы, роли, подтверждение перевода для точных файлов/выборок, отказ при черновике, отмена/ошибка записи, stale/retry, Unicode, повреждённая библиотека рядом с исправной. Подготовленный материал импортируется в независимые подачи со своими номерами без вызова Claude/Codex.
- `test_library_versions.py`: новый перевод/оригинал, таблица отличий/удалённая часть, обновление только B и возврат к v1, сохранность A/исходников/старых ZIP; местные название/выборка/перевод/оформление, диапазон вне новых страниц, устаревший выбор, отказ записи с проверенным снимком. ID, номер, папка, имя и назначения ссылок сохраняются.
- `test_library_backup.py`: все версии, сохранение ID и независимая копия, повтор восстановления, последующее соединение подачи с библиотекой, экспорт без библиотеки, отмена/диск, traversal/symlink/повтор ZIP/future schema/лимиты. Проверяются фактические страницы PDF: поддельные размеры при валидных SHA-256 отклоняются. Коллизия назначения архива не удаляет прежний ZIP.
- `test_library_bulk.py`: 100 разных PDF и экспорт всего выбранного набора, явные роли/пары, исключение ошибочной строки, атомарность после сбоя копирования, Unicode-конфликты пути, метки/фильтры/точные дубликаты, локальное использование с копией/повреждённой подачей, скрытие/возврат без изменения файлов. Равный оригинал с иным переводом не объединяется автоматически.
- `scripts/library_checks.py`: две библиотеки/две подачи/20 материалов; A: Annex 3, B: Annex 12; v2 только в B и возврат v1, хеши A/истории неизменны, отсутствие библиотеки не мешает экспорту.
