# Проверки реализации 0.5.0

Обновлено 9 октября 2026. Ветка `codex/case-material-library` начата от принятого плана `fc62480`. Это доказательства реализации, не объявление выпуска. Публикация GitHub Release не разрешена.

## Выполненные срезы

- `tests/test_library.py`, `test_library_api.py`, `test_library_versions.py`, `test_library_backup.py`, `test_library_bulk.py`: валидные/повреждённые схемы; атомарность и сбои до/после копирования; отмена, устаревший выбор и идемпотентность; роли, привязка перевода и исключение черновика; собственные номера/файлы; обновление только B и возврат v1; конфликты местного названия/выборки/перевода, диапазон за новыми страницами; проверенные снимки при ошибке записи; два типа архива, конфликт/копия, недопустимые ZIP; 100 PDF, исключение ошибок, дубликаты, фильтры, справка локальных подач, скрытие без изменения файлов.
- Полная проверка исходников Windows: 268 Python-тестов и 23 JS-теста прошли. Изменение выборки теперь снимает подтверждение применимости перевода: прежний тест обновлён с проверкой отказа до повторного подтверждения.
- Edge 154, Windows 11, интерфейс из исходников: сохранение оригинала и подтверждённого перевода → другая подача/Annex 12 → подтверждение оформления → ZIP. Хеши исходной подачи неизменны. Просмотр и отсутствие переполнения/JS-ошибок — 1440/760/390.
- Там же: публикация v2 с новым переводом, сравнение на широком/узком экране, явное обновление B с сохранением ID/Annex 12; скачивание архива и восстановление независимой копии библиотеки. Это проверка браузерного интерфейса, не Word.
- `scripts/library_ui.cjs`: старый путь готовый PDF → ZIP без библиотеки; загрузка 100 различных искусственных PDF, общая роль, публикация, импорт трёх, «где используется», скрытие/возврат, Escape и возврат фокуса. Реакция интерфейса на загрузку — 36,5 мс; JS-ошибок и переполнения на трёх размерах нет.
- `scripts/verify_library.py` / `library_checks.py`: две библиотеки/две подачи/20 материалов, Annex 3 и Annex 12, обновление только B/возврат v1, неизменность A/исходников/старых ZIP, экспорт без библиотеки. Переводы берутся из искусственных PDF; команды перевода не запускаются.
- `scripts/generate_legacy_archives.py` создаёт искусственные архивы **кодом опубликованных тегов v0.3.0 и v0.4.0**; восстановление и экспорт в новых исходниках прошли, исходные файлы и история совпали побайтово, schema 1 не переписывается при открытии.
