## Context

Реализация находится в `codex/word-workflow`. Реальный Office.js проверен на Microsoft 365 Windows 16.0.17928.20148; Mac остаётся открытым. Мотивация — в proposal.md. Найденная при миграции ошибка изоляции HTTPS исправлена; основное приложение работает без подключения панели.

## Goals / Non-Goals

Общий Store и существующие API обслуживают оба пути. Не создаём отдельную базу для панели, обязательный аккаунт или новую службу. Конвертация DOCX→PDF остаётся самостоятельной зависимостью.

## Decisions

- Постоянные ID в управляемых ссылках позволяют менять номера и имена файлов. Альтернатива — поиск только по видимому названию — не даёт однозначности.
- Вставка Flat OPC одним действием отделяет ссылку от locator. Последующее очищение `range.hyperlink` у соседнего фрагмента в реальном Word удаляло основную ссылку.
- Перед обновлением повторно читаем диапазоны и сверяем план. Автоматическое перезаписывание ручных изменений исключено.
- Опциональный HTTPS запускается через отдельную обёртку: ожидаемые ошибки конфигурации/сертификата/порта дают `configured: false` и понятный статус; HTTP продолжает работу. Не скрываем ошибки самого основного сервера и не меняем настройки доверия Windows.
- Текст ошибки виден в разделе подключения. Пользователь может продолжить обычную загрузку DOCX; сертификат не удаляется и не устанавливается автоматически.

## Risks / Trade-offs

- Отличия Office.js Windows/Mac → живые проверки отдельно от эмуляции.
- Перед заменой сервер обрабатывает исходный Flat OPC ссылки: сохраняет свойства фрагментов обозначения и названия. Смешанное оформление внутри одной части и сложные элементы отклоняются до записи. После подготовки всех фрагментов панель повторно сверяет текст, XML и режим исправлений. Проверки XML и обмен через настоящий Word Windows прошли; это не заменяет живую приёмку кнопки Office.js.
- Потеря последних исправлений при слиянии → интеграционная проверка правил rc.5 до выпуска.

## Migration Plan

Изоляция HTTPS не меняет формат проекта. Пользователь может заново настроить панель; работа с существующими DOCX остаётся доступна. Изменения rc.5 объединены, пакеты v0.2.0 прошли проверки. Источники/сертификаты не перезаписывать.
