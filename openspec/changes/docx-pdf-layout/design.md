# Design

## Context

См. proposal.md. В переданной тройке различаются только части сносок DOCX; разделители и основной document.xml сохранены. Итоговый PDF LibreOffice ARM использует замену Times New Roman и разрывает неподкреплённые keepNext абзацы рядом с плавающим изображением. Причинность подмены шрифта и влияние подготовки копии пока не установлены.

## Goals / Non-Goals

**Goals:** измерить четыре стадии конвертации в одинаковой среде; реализовать минимальное преобразование только при доказанном дефекте; контролировать отступ с допуском 1 pt, положение блока, содержание и переносимые ссылки.

**Non-Goals:** менять пользовательский DOCX, подгонять конкретную страницу, применять keepNext всем абзацам, менять поля/интервалы, распространять проприетарные шрифты, использовать экспорт LibreOffice как эталон Word.

## Decisions

1. До изменения кода сохранить хеши эталонов и измерить source → direct, linked → direct, marked/prepared → converted и converted → portable. Хеши содержимого страниц и геометрия проверяются отдельно от изменяемых аннотаций.
2. Для Word используется имеющийся изолированный процесс; для LibreOffice — отдельный профиль без изменения открытой сессии пользователя. Рабочие документы не отправляются в CI.
3. Искусственные примеры включают разные отступы/поля/продолжение, начертания шрифта, плавающее изображение и контроль с явной связью абзацев. Только эти файлы используются в нативном CI.
4. Решение разделителя/подписи уточняется по результатам прямых экспортов. Область преобразования должна следовать структуре OOXML и не затрагивать соседний текст. Предупреждение о шрифте само по себе не означает исправления подписи.
5. Новая версия преобразования должна менять ключ кеша. Старые архивы/ZIP и исходники не переписываются.

## Risks / Trade-offs

- Разные движки разбивают страницы по-разному → независимый Word-эталон, одинаковые шрифты, отдельная таблица сред.
- Исходник не задаёт связь подписи с именем → не угадывать семантику изображения; зафиксировать предел и конкретный вариант для согласования.
- Наличие файла шрифта не доказывает его выбор LibreOffice → измерять PDF-шрифты и доступность для процесса.
- Mac-проверка рабочего документа недоступна локально → искусственные примеры в нативном Mac CI и честный отдельный статус точного рабочего примера.
