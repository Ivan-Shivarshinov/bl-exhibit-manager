## ADDED Requirements

### Requirement: Однократная проверка общего PDF для одинаковой политики
Проверка архива SHALL переиспользовать результат разбора общего PDF для ссылок с одинаковыми правилами допуска полей и подписей только внутри одной операции. Каждая ссылка SHALL сверять свои сведения о страницах; новая операция проверяет байты заново.

#### Scenario: Много ссылок на один исходник
- **WHEN** документы с разными идентификаторами ссылаются на один PDF
- **THEN** дорогой разбор выполняется один раз для каждой применённой политики, без роста числа разборов по числу ссылок

#### Scenario: Разные политики и повреждённая метаинформация
- **WHEN** один файл используется как готовый оригинал и как обрабатываемый оригинал или перевод, либо одна ссылка содержит неверные сведения о страницах
- **THEN** разрешение полей готового оригинала не переносится на строгие роли, неверная ссылка отклоняется независимо от порядка документов

#### Scenario: Изменение архива перед восстановлением
- **WHEN** байты меняются между предпросмотром и восстановлением либо во время записи
- **THEN** старая проверка не заменяет новую, частичный проект не публикуется, исходные проекты и прежние ZIP сохраняются
