## MODIFIED Requirements

### Requirement: Готовые PDF без переоформления
Приложение SHALL предоставлять массовый импорт и переключение готовых PDF в режим без обработки, без обязательного подтверждения внешнего вида каждого файла.

#### Scenario: Уже оформленная подача
- **WHEN** пользователь загружает готовые PDF в этом режиме
- **THEN** экспортируемые PDF побайтово совпадают с исходниками, а проверки имён и целей ссылок сохраняются

#### Scenario: Поля и структуры подписи в готовом PDF
- **WHEN** читаемый PDF содержит реальные поля формы, виджеты либо структуру подписи и добавляется как готовый
- **THEN** файл принимается без изменения байтов, включая просмотр и экспорт; действительность подписи не утверждается, пустой AcroForm сам по себе не считается подписью

#### Scenario: Попытка переоформления формы или подписи
- **WHEN** такой PDF загружается для подготовки либо переводится из готового режима в подготовку через интерфейс, массовое действие или API
- **THEN** операция отклоняется до изменения подачи с предложением добавить готовый PDF; поля не удаляются, файл не растрируется и не перепечатывается

#### Scenario: Недопустимый готовый PDF
- **WHEN** PDF повреждён, зашифрован или превышает действующие ограничения размера и страниц
- **THEN** готовый режим не обходит отказ проверки, исходная подача сохраняется
