## Purpose

Сохранение редактируемого проекта целиком и продолжение работы на другом компьютере без потери материалов, решений и ранее собранных комплектов.

## ADDED Requirements

### Requirement: Полный архив отдельного проекта
Приложение SHALL по команде пользователя создавать самодостаточный архив проекта, включающий исходники, настройки, решения по ссылкам, сохранённые черновики и подтверждённые переводы, историю комплектов и сведения для проверки целостности.

#### Scenario: Продолжение незавершённой работы
- **WHEN** проект содержит готовые приложения, несопоставленную ссылку и незаконченный перевод
- **THEN** архив сохраняет эти состояния; восстановление не выдаёт их за проверенные и не запускает перевод автоматически

#### Scenario: Сохранение результатов
- **WHEN** проект с двумя собранными комплектами сохранён и восстановлен
- **THEN** исходные файлы и оба прежних ZIP доступны с теми же байтами, а настройки и решения позволяют продолжать работу

### Requirement: Согласованный снимок без данных компьютера
Приложение SHALL сохранять согласованное состояние одного проекта и исключать учётные данные, закрытые ключи, сертификаты, журналы, внешние исполняемые файлы и настройки подключения конкретного компьютера.

#### Scenario: Проект меняется во время сохранения
- **WHEN** идёт запись перевода или другой результат меняется во время подготовки архива
- **THEN** приложение выдаёт согласованный снимок либо просит дождаться завершения операции; смесь разных состояний не выдаётся как готовая копия

#### Scenario: Перенос без установленных зависимостей
- **WHEN** архив открыт на компьютере без панели, конвертера и аккаунта переводчика
- **THEN** восстановление доступно; зависимости требуются только для операций, которым они нужны, и не импортируются из архива

### Requirement: Проверка до восстановления
Приложение SHALL до изменения списка проектов проверять формат архива, обязательные файлы, ссылки между данными, размеры и контрольные суммы; небезопасные пути, ссылки файловой системы и дубли записей должны отклоняться.

#### Scenario: Повреждённый или неполный архив
- **WHEN** не совпадает контрольная сумма либо отсутствует обязательный исходник или сохранённый ZIP
- **THEN** восстановление прекращается с понятной причиной, существующие проекты остаются прежними

#### Scenario: Недопустимый архив
- **WHEN** запись выходит за каталог восстановления, повторяет путь либо распакованный размер превышает допустимый предел
- **THEN** импорт отклоняется без записи за пределами временного каталога и без появления частичного проекта

### Requirement: Явный выбор при конфликте
Приложение SHALL показывать имя, состав и совместимость проекта до восстановления; существующий проект нельзя перезаписывать. При совпадении идентификатора доступно явное восстановление независимой копии с новым локальным идентификатором.

#### Scenario: Проект уже существует
- **WHEN** пользователь выбирает архив существующего проекта
- **THEN** показан конфликт и варианты отменить либо создать копию; исходный проект и его история не изменяются

#### Scenario: Копия содержит управляемые ссылки Word
- **WHEN** восстановлена независимая копия проекта со ссылками панели
- **THEN** выбор копии и проверка ссылок связывают их с материалами копии; приложение не подставляет молча документы из прежнего проекта, исходный DOCX сохраняется неизменным

#### Scenario: Повторное чтение ссылки перед обновлением копии
- **WHEN** при применении обновления в копии Word повторно сериализует тот же фрагмент, меняя только служебные XML-данные
- **THEN** ссылка обновляется с сохранением начертания; реальная правка текста, адреса или оформления во время подготовки блокирует все выбранные обновления до записи

### Requirement: Атомарное восстановление и переносимость
Приложение SHALL делать восстановленный проект доступным только после завершения всех проверок и записей. Архив должен переноситься между Windows и macOS без изменения содержимого исходников и истории.

#### Scenario: Сбой записи
- **WHEN** заканчивается место или восстановление прерывается
- **THEN** частичный проект не показывается как готовый, архив и существующие проекты остаются доступны, повторная попытка возможна

#### Scenario: Windows и Mac
- **WHEN** архив создан на Windows и восстановлен на Mac либо наоборот
- **THEN** доступны материалы, переводы, сопоставления и прежние ZIP; новый комплект содержит корректные относительные цели после настройки нужного конвертера
