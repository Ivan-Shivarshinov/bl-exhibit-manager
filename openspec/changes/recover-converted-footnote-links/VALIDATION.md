# Проверка восстановления ссылок

22 октября 2026. Исправление не опубликовано.

- Адресный прогон `tests.test_pdf_link_recovery tests.test_main_pdf`: 20 проверок пройдены. Искусственные случаи: перенесённая сноска, повторяющийся текст, многострочная ссылка, неверный номер/текст, отсутствующая структура, неоднозначность, обычные ссылки, конфликт кликабельных областей, доказанное исправление области соседней ссылки, блокировка PDF/ZIP при неполноте.
- Изолированный LibreOffice 26.8.0.3 Windows: частный пример воспроизводит потерю аннотаций до исправления; после исправления проверка всех ожидаемых маркеров проходит. Потоки содержимого всех страниц побайтно прежние; пиксели затронутых страниц при отрисовке без аннотаций совпадают. Рабочие материалы и результаты остаются вне Git.
- `scripts/verify_link_recovery_office.py`: настоящий LibreOffice, искусственный документ, намеренно удалённые PDF-аннотации. Отрицательный контроль блокирует выдачу; восстановление даёт ZIP с относительными целями, исходник и содержимое страниц сохраняются. Это контролируемая имитация потери аннотаций, а не естественное воспроизведение ошибки LibreOffice на этом искусственном документе.
- Во время первого полного экспорта частного проекта через HTTP все параллельные проверки `/api/health` успешны. По коду конвертация не держит глобальную блокировку, ошибка PDF даёт HTTP 400 и не останавливает сервер. Отдельное сообщение «Нет связи» не воспроизведено, исправленным не объявляется; фронтенд не изменён.
- Общий локальный прогон: 300 тестов, один сбой существующего теста доверия сертификатам Word. В этой среде пустой `ssl.SSLContext` уже содержит один CA, а тест ожидает пустое начальное хранилище. Повтор отдельного теста даёт тот же результат; файлы настройки Word не менялись. Адресные PDF-тесты успешны. Нативный CI предстоит проверить отдельно.
- Строгая проверка OpenSpec: 13/13. Версия кеша основного PDF повышена, старые ZIP не изменяются.
- Итоговый повтор полного HTTP-экспорта после добавления исправления конфликтующей соседней области успешен. Все ожидаемые ссылки подтверждены, все цели присутствуют в ZIP; исходник и не затронутые ссылками части DOCX сохранены. Все 99 запросов здоровья успешны (максимум 0,172 с).
- CI первого коммита: общий набор тестов Windows и Mac ARM пройден; Mac ARM полностью прошёл пакет и настоящий LibreOffice. В Windows проверка пакета получила HTTP 500 при предварительном просмотре архива. Отдельным регрессионным тестом воспроизведена гонка: завершение скачивания удаляет временную папку между `is_dir` и `stat` следующей операции архива. Она исправлена; это подтверждённый дефект, но без трассировки того запуска не объявляется доказанной причиной CI-ошибки. При последующих сбоях проверки пакета теперь сохраняют журнал сервера. Требуется повтор CI.
