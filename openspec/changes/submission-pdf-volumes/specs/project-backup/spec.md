## ADDED Requirements

### Requirement: Независимый перенос профиля и производных
Архив SHALL содержать применённый профиль, настройки/назначения томов, происхождение производного основного DOCX и готовую историю; восстановление не требует общего каталога профилей.

#### Scenario: Другая платформа без библиотеки
- **WHEN** подача с профилем/перенумерацией/томами восстановлена на другой целевой платформе без каталога профилей и библиотеки
- **THEN** правила/назначения/исходники/прежние ZIP сохранены, новый комплект собирается без повторного перевода

#### Scenario: Старый клиент
- **WHEN** архив нового формата открывается старым приложением
- **THEN** несовместимый формат отклоняется без потери новых полей и без изменения существующего проекта
