## ADDED Requirements

### Requirement: Поисковые и структурные производные
Приложение SHALL явно сохранять поисковый PDF и поддержанные поворот, объединение и разделение как отдельные производные с происхождением.

#### Scenario: Поисковая копия скана
- **WHEN** пользователь запрашивает поисковый PDF
- **THEN** новая копия ищется по распознанным словам, вид страницы и исходный файл сохраняются, а неподдерживаемые структуры и подпись обрабатываются с понятным ограничением

#### Scenario: Поворот, объединение или разделение
- **WHEN** пользователь указывает страницы для поворота, упорядоченные диапазоны для объединения или состав всех частей для разделения
- **THEN** приложение скачивает отдельные файлы с указанием операции, исходных PDF и номеров их страниц, сохраняя исходники

#### Scenario: Навигацию невозможно сохранить
- **WHEN** запрошенное преобразование не может сохранить форму, подпись или навигацию исходного файла
- **THEN** приложение объясняет ограничение и сохраняет исходный PDF
