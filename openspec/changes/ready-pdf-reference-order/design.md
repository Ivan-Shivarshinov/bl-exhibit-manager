## Context

Проверка PDF запрещает поля до выбора режима, два списка назначения отображают исходный массив. Исправляется опубликованная линия от main; библиотека сохранена отдельно.

## Goals / Non-Goals

Не менять схему/байты источников. Не подтверждать подпись и не добавлять редактор форм; панель и вёрстка основного документа не меняются.

## Decisions

- Читаемость и ограничения проверяются отдельно от разрешения преобразования. Готовый путь допускает реальные поля/виджеты/структуры подписи; подготовка явно запрещает их. Проверка нужна перед изменением режима и на самом преобразовании, чтобы нельзя было обойти её через API или архив.
- Анализ охватывает дерево полей, аннотации страниц и каталожные структуры подписи. Пустое дерево не равнозначно подписи; виджеты без AcroForm остаются ограниченными для преобразования. Предпросмотр инициализирует формы и рисует аннотации, не сохраняет изменения PDF.
- Общая чистая функция сортирует копию массива по эффективному обозначению, префиксу и числовому номеру; естественное сравнение текста, затем имя/ID. Меняется только порядок option, значения остаются ID.
- В архиве каждый источник проверяется по фактическому режиму/роли. Общий blob с несколькими ролями не получает разрешение переоформления из-за готовой роли. Метаданные страниц сверяются с содержимым, без новой схемы.

## Risks / Trade-offs

- Циклические/повреждённые PDF-структуры → ограниченное чтение и существующий понятный отказ, без flattening.
- Форма без appearance → сохранение байтов, показ доступного внешнего вида; отрисовка не проверяет криптографию.
- Готовый PDF в библиотеке → разрешение только роли ready; prepare/original/translation сохраняют запрет преобразований.

## Migration Plan

Исправительная 0.4.1 от main, затем перенос кода в 0.5.0 отдельным коммитом и дополнительная проверка библиотеки. Старые проекты/архивы читаются без миграции. Три нативных пакета каждой линии проверяются до заявления готовности; PR и релиз автоматически не публикуются/не объединяются.
