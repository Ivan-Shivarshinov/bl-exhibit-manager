# Proposal

## Why

Сканирование ревизии 2bbb7eb7 выявило доступ другой локальной учётной записи к проектам через API и многократный разбор общего PDF при восстановлении архива. Пользователь поручил исправить обе находки до выпуска кандидата 0.6.0; это согласованное исправление безопасности, не новый этап ROADMAP.

## What Changes

- Все чтения документов и изменения API требуют полномочия владельца на HTTP и необязательном Word HTTPS. Обычный запуск сам открывает авторизованный интерфейс, без пароля и ручного копирования ключей.
- **BREAKING:** постоянного X-Exhibit-Local недостаточно для прямых API-клиентов; локальные проверочные инструменты получают сессию через приватные данные владельца.
- Панель Word получает доступ после явного подтверждения совпадающего кода в приложении. Сертификат, XML и регистрация не меняются; разрешённая панель восстанавливает сессию после перезапуска.
- Общий PDF проверяется один раз для каждого режима допуска полей/подписей внутри отдельной проверки архива. Каждая ссылка продолжает проверять свою метаинформацию; форматы архивов не меняются.

## Capabilities

### New Capabilities

- `local-access`: приватный запуск владельца, авторизованные сеансы браузера и разрешённой панели, отказ посторонним локальным клиентам.

### Modified Capabilities

- `project-backup`: отсутствие повторной дорогой проверки одного исходника при множестве ссылок с сохранением строгих правил каждой роли.

## Impact

Локальный API, запуск/повторный запуск/остановка, защита файла полномочия на Windows/macOS, интерфейс и необязательная панель, проверки и пакеты кандидата. Исходники документов, проекты, прежние ZIP, переводчики и конвертеры не изменяются. Вне объёма: сетевой/многопользовательский сервис, аккаунты/облако, публикация релиза и объединение PR, изменение механизмов регистрации Word или глобальной блокировки снимка проекта.
