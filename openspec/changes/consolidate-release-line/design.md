## Context

База OpenSpec отражает принятый пилот rc.5; текущая ветка Word старше этих исправлений. Краткий README и инструкция разработчика опубликованы в main отдельно. См. таблицу версий в `openspec/README.md`.

## Goals / Non-Goals

Получить единую проверенную линию без потери пользовательских решений и файлов. В этом change нет новых требований: проверяются пять базовых спецификаций и завершённые изменения следующего этапа. Новые идеи ROADMAP не включаются в слияние автоматически.

## Decisions

- Сверить обе ветки и выполнить обычную интеграцию с ручным разбором конфликтов. Не копировать весь старый файл поверх нового и не переписывать опубликованную историю.
- Отдельно проверять импорт готовых PDF, ссылку без файла, ручные/исключённые упоминания, форматирование и папки: эти участки менялись по обе стороны.
- Проверки пакетов обязательны после интеграции; успешный CI предыдущего тега не считается доказательством новой версии.
- Документация пользователя краткая; техническая история остаётся в Git/OpenSpec, частные материалы не включаются в коммит или релиз.

## Risks / Trade-offs

- Старый формат ссылок возвращается при слиянии → проверка жирного обозначения и сохранённого курсива в готовом PDF.
- Модель редакций не знает новых решений → отдельные сценарии `submission-revisions-and-history`.
- Разные внешние конвертеры → реальные проверки Word/LibreOffice и честная матрица сред.

## Migration Plan

Сохранить старую проверочную версию доступной. Проверить резервную копию тестового проекта, открытие после обновления и возврат к прежней версии в пределах совместимого формата. Только затем собирать новый проверочный пакет; стабильный релиз не объявлять по одному успешному сценарию.
