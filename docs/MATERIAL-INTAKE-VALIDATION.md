# Проверка 0.8.0

Проверены пакеты сборки `a7c2f98` на CPython 3.12.10. Во всех трёх пакетах сверены версия, платформа, коммит и SHA-256. ZIP и `SHA256SUMS.txt` находятся в `release/0.8.0/`. [CI 45582778202](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/actions/runs/45582778202).

| Пакет | Tesseract | Языковые данные |
|---|---|---|
| Windows x64 | 5.4.0.20240606 | `eng`, `rus` |
| macOS Intel | 5.5.3 | `eng`, `rus` |
| macOS Apple Silicon | 5.5.4 | `eng`, `rus` |

На каждой платформе распакованный пакет открыл проект, созданный публичной 0.7.0. Два искусственных PDF содержали страницу со встроенным текстом и растровую страницу на одном из двух языков. Очередь переиспользовала готовую страницу. Правка OCR появилась в поиске, в версии библиотеки и в отдельном поисковом PDF. Пара из двух папок прошла явное подтверждение, а импортированный перевод получил переход на нужную страницу тома. Исходный PDF вошёл в ZIP байт в байт. Ранее собранный ZIP сохранился.

Свежий профиль без Tesseract восстановил проект и нашёл исправленный текст. При обмене каждый из трёх пакетов восстановил проекты со всех трёх платформ, нашёл правку OCR и повторно собрал том. Пакет 0.7.0 оставил проект новой схемы без изменений и открыл резервный архив прежней схемы со старым экспортом.

В Chromium на Windows проверены импорт папки с парой и дубликатами, переходы к сноске, фрагменту и версии библиотеки, отдельное скачивание разделённого PDF и выбор проверенного OCR в предпросмотре перевода. Отправка текста провайдерам в этот сценарий не входила. Все документы и папки проверки искусственные.
