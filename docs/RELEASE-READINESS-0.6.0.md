# Готовность к этапу 0.6.0

Проверено 29 октября 2026. Аудит и планирование; код приложения, main и опубликованные релизы не менялись.

## Вывод

Планировать 0.6.0 можно. Перед реализацией новых функций нужен подготовительный этап: привести основную ветку к выпущенному коду, разобрать повторяющийся сбой браузерной проверки библиотеки и синхронизировать старые изменения OpenSpec. Это конкретные хвосты разработки, а не требование новой общей ручной приёмки.

Последний публичный релиз — v0.5.1, опубликован 23 октября. Его пакеты взяты из успешного CI 39811591700 для `698b94210f567ed557d8714b397adfff930a3fc1`; три платформы и обмен архивами успешны. Позднее тот же код проверялся по событию создания тега, и этот отдельный прогон выявил повторный сбой. Нельзя описывать все прогоны этого коммита как успешные.

## Проверенное в этом аудите

- Рабочее дерево перед планированием чистое; runtime текущей ветки = 0.5.1. GitHub Release и состояния проверок прочитаны заново.
- **118 Python-тестов успешно**: `test_workflow`, `test_batch`, `test_submission_folders`, `test_translation_layout`, `test_ready_pdfs`, `test_citation_controls`, `test_word_workflow`, `test_word_optional`, `test_pdf_link_recovery`, `test_backup`.
- **14 Python-тестов успешно**: `test_feedback`, включая штамп в существующих полях и сохранение размеров/расположения содержимого.
- **25 JavaScript-тестов успешно**: `node --test web/tests/*.test.js`; это модульные проверки, включая имитации Word, не новая проверка в настоящем Office.
- Нативный полный CI 39811591700 и отдельный неуспешный CI тега 39927092607 проверены по GitHub. Повторные сборки в этом аудите не запускались.
- Новый план: 9 требований, 23 сценария, 35 задач; все задачи реализации открыты. Строгая валидация OpenSpec: 13/13, локальные ссылки документов проверены.

## Условия начала основной части 0.6.0

1. Выполнены подготовительные задачи 0.1–0.4 нового плана.
2. Есть единая актуальная база требований и сборки; известный повторяющийся отказ CI разобран с доказательствами.
3. Для перечня зафиксированы состав, порядок, ссылки, отсутствие обязательного Office, совместимость архивов и критерии выдачи целого комплекта.
