# Сноски без PDF и элементы Word: 0.1.3-rc.2

Эта версия продолжает исправления на базе v0.1.2. Длинные PDF из rc.1
поддерживаются. Новая панель Word из отдельной ветки разработки не включена.

## Без файла

В списке «Соответствующий файл» есть вариант **«Без файла — оставить как есть»**.
Выбирайте его для упоминаний, которым намеренно не соответствует PDF: например,
для видео с уже вставленной ссылкой на YouTube. Статус меняется на
«Без файла · без изменений». Текст, оформление и существующая веб-ссылка
сохраняются; новая гиперссылка не создаётся. Если URL был обычным текстом,
этот режим не превращает его в гиперссылку.

Выбор относится к упоминанию в строке. Другие приложения в той же сноске могут
быть связаны с PDF. Флажок применения к одинаковым упоминаниям действует и
для этого варианта. Решение сохраняется после перезапуска и повторного
сопоставления того же DOCX. Можно снова выбрать файл или вернуть строку в
несопоставленное состояние. Неопределённый выбор продолжает блокировать экспорт.

Чтобы собрать DOCX/PDF, фиктивный файл больше не нужен — допускается комплект
только с основным документом и явно подтверждёнными упоминаниями без файлов.

## Структура Word

Вставка ссылок теперь сохраняет табуляции, переносы строк, специальные дефисы,
маркер номера сноски и служебный маркер разрыва страницы в смешанных фрагментах
Word. Такие фрагменты воспроизводили прежнюю ошибку «Неподдерживаемая структура
внутри упоминания». Повторение Annex в названии допустимо.

Неподдерживаемые элементы не удаляются автоматически: операция останавливается
и показывает номер сноски, а для неподдерживаемого содержимого текстового
фрагмента — название элемента. Поля Word, исправления и элементы управления
по-прежнему требуют отдельной проверки. Случай коллеги в сноске 97 пока не
подтверждён на исходном DOCX: доступны только скриншоты.

## Проверка коллегой

1. Остановить прежнюю версию, распаковать весь новый ZIP и запустить Start.
2. В существующей подаче повторить «Сопоставить ссылки».
3. В строках видео вместо временного Annex 9 выбрать «Без файла — оставить как
   есть». Проверить остальные повторения, особенно ссылки с разными таймкодами.
4. Нажать «Все сноски проверены» и собрать ZIP.
5. Проверить сноску 97 в DOCX и PDF: оба названия должны вести к своим PDF,
   уточнения страниц/параграфов остаются вне ссылок. Ссылки видео должны вести
   на прежние URL с прежними таймкодами.
6. Если сноска 97 всё ещё блокирует сборку, передать DOCX либо копию с этой
   сноской, на которой ошибка воспроизводится, и полное сообщение ошибки.

Автотесты и проверка реальным Office используют только вымышленные документы.
Документы и скриншоты коллег в установочные архивы и репозиторий не включаются.
