# Исправление длинных PDF на базе v0.1.2

Ветка `codex/v012-pdf-hotfix`, проверочная сборка `0.1.3-rc.1`.
Разработка панели Word сохранена отдельно в `codex/word-workflow` (PR #2).

## Исправление

PDF размером до 14 400 пунктов по каждой стороне принимаются вместо прежнего
ограничения в 3000. Длинные страницы не разбиваются и не уменьшаются в готовом
PDF. Предпросмотр ограничен 12 млн пикселей и стороной 16 000 пикселей.
Проверка пересечения штампа с содержимым рендерит только область штампа.
Извлечение фрагмента рендерит только выбранную область, с ограничением 24 млн
пикселей. Защита от наложения штампа на содержимое сохранена.

Проверено на локальных Annex 46 (1304×6121, 1 страница) и Annex 59
(1440×4507,92 и 1440×4508, 2 страницы): импорт, сборка, предпросмотр всех страниц.
Файлы коллег не включены в репозиторий или автоматические проверки GitHub.
Регрессионные тесты используют только искусственные документы.

## Отдельная ошибка DOCX

«Неподдерживаемая структура внутри упоминания» не связана с размерами PDF.
Теперь сообщение содержит номер проблемной сноски. Причина именно в документе
коллеги не установлена: основной DOCX не предоставлен. Исправление PDF не
объявляется исправлением этой ошибки. Для воспроизведения нужен исходный DOCX
или его копия с проблемной сноской и сохранённой структурой Word.

## Проверка коллегой

1. Остановить прежнее приложение и распаковать новую сборку целиком в отдельную
   папку. Существующая папка проектов остаётся прежней.
2. Повторно добавить PDF, отклонённые старой версией: они не сохранились при
   неудачной загрузке. Остальные документы заново добавлять не нужно.
3. Проверить оригинал и результат, включая нижнюю часть длинной страницы.
   Если сверху нет свободного места, выбрать дополнительную полосу для штампа
   или режим без обработки, если документ уже оформлен.
4. Повторить сопоставление ссылок. При ошибке DOCX передать номер сноски и DOCX
   для отдельной диагностики; не считать подачу готовой по одному импорту PDF.
