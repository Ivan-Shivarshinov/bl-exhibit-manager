Теперь в подачу можно добавить перечень приложений с названиями, числом страниц и ссылками на PDF.

### Что нового

- Перечень в DOCX и PDF включается в ZIP вместе с приложениями. Число страниц учитывает перевод и выбранные фрагменты.
- Можно выбрать русский или английский язык, свой заголовок, колонки и порядок документов. Перед сборкой доступен предпросмотр.
- После изменения документов приложение предлагает обновить перечень. Прежние комплекты сохраняются в истории.
- Исправлено создание новой библиотеки во время загрузки списка материалов.
- Усилена защита проектов на компьютере и исправлена задержка при проверке некоторых архивов проектов.

### Как обновиться

Сохраните архив проекта. Остановите прежнюю версию через `Stop.cmd` (Windows) или `Stop.command` (Mac). Распакуйте весь ZIP в новую папку и запустите `Start.cmd` (Windows) или `BLExhibitManager.app` (Mac). Существующие проекты сохраняются. Для запуска используйте эти файлы, а не сохранённую ссылку в браузере.

Если используете панель Word, закройте её и откройте заново. Сравните показанный код с кодом в «Помощь и настройка» и разрешите подключение. Повторная установка панели не требуется. Панель остаётся необязательной.

При первом сохранении настроек перечня приложение создаст резервный архив и обновит формат проекта. Для возврата к 0.5.1 понадобится архив проекта, сохранённый до этого обновления. Отключение перечня не возвращает прежний формат.

### Как добавить перечень

В «Проверка и экспорт» отметьте «Добавить перечень приложений», выберите настройки и нажмите «Сохранить перечень». Затем нажмите «Обновить перечень», проверьте таблицу и соберите ZIP.

Передавайте всю распакованную папку Submission, сохраняя вложенные папки: они нужны для переходов к приложениям.

### Требования и ограничения

Для создания перечня Word и LibreOffice не нужны. Для подготовки основного PDF из DOCX нужен Microsoft Word на Windows либо LibreOffice на Windows/Mac.

Для переходов из PDF-перечня на Windows используйте SumatraPDF 3.6.1. В версии 3.5.2 не работают ссылки с `#` в пути; PDF24 Reader 11.30.1 переходы к файлам не выполняет. DOCX-перечень открывайте в настольном Word.

Пакеты пока без подписи издателя: система может показать предупреждение при первом запуске.
