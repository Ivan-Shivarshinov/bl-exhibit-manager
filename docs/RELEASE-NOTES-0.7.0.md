В этой версии можно сохранить правила оформления для следующих подач, согласованно изменить назначенные номера и собрать приложения в PDF-тома.

### Что нового

- Профили оформления с собственными названиями и версиями. Их можно перенести в другое приложение отдельным файлом и проверить изменения перед применением. Местные исключения и ручные имена сохраняются по умолчанию.
- Изменение уже назначенных номеров, обозначений, папок и имён, включая обмен занятых номеров. Известные упоминания DOCX обновляются после проверки; исходный документ сохраняется.
- Один или несколько PDF-томов с перечнем, разделителями, закладками, общей нумерацией и переходами. Можно задать порядок и предел страниц или размера каждого тома.
- Выбор страницы перехода из основного документа с картой исходных и подготовленных страниц. Приложение предупреждает, если выбранная страница устарела после изменения материала.
- Предпросмотр томов, отмена сборки и повтор после ошибки. Отдельные приложения и прежние комплекты остаются доступны.

### Как обновиться

Сохраните архив проекта. Остановите прежнюю версию через `Stop.cmd` (Windows) или `Stop.command` (Mac). Распакуйте весь новый ZIP в отдельную папку и запустите `Start.cmd` (Windows) или `BLExhibitManager.app` (Mac). Проекты сохраняются.

При первом применении новых правил, назначений или настроек томов приложение обновит формат проекта и создаст резервный архив. Для возврата к 0.6.0 используйте архив, сохранённый до этого обновления. Отключение томов не возвращает старый формат.

### Как собрать тома

Откройте «Проверка и экспорт» → «PDF-тома», включите режим и сохраните настройки. Нажмите «Подготовить PDF-тома», проверьте состав, страницы и изображение, затем скачайте ZIP. Передавайте всю распакованную папку Submission, сохраняя её структуру.

Обычный ZIP без томов остаётся доступен. Word и переводчик для сборки готовых PDF не нужны. Для включения основного DOCX в том потребуется конвертер: Microsoft Word на Windows либо LibreOffice на Windows/Mac. Панель Word необязательна, её повторная установка не нужна.

### Ограничения

Подпись отдельного PDF не удостоверяет новый составной том. Подписанные оригиналы сохраняются отдельными файлами. Если безопасный перенос элемента PDF невозможен, приложение остановит сборку и объяснит причину.

Номер параграфа не считается номером страницы автоматически. Выберите подготовленную страницу перехода либо явно подтвердите начало материала. Для продолжения работы в уже открытом Word обновите управляемые ссылки прежней командой панели; изменение назначений в приложении само по себе не меняет открытый документ.

Пакеты пока без подписи издателя: система может показать предупреждение при первом запуске.
