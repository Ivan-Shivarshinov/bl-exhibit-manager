# Следующий этап: работа над подачей в Word

Согласован 15 сентября 2026 года. Windows и Mac — равноправные целевые среды.

## Последовательность

1. Прототип Word: локальное HTTPS-подключение, панель приложений, вставка настоящей сноски, сохранение связи в DOCX, экспорт с относительной ссылкой. Проверить на Windows; живую проверку Word на Mac передать команде.
2. Создание сносок: полное/короткое название, отдельное указание страницы/параграфа/статьи, несколько документов, добавление в существующую сноску, настройки подачи.
3. Обновление ссылок: показать старое и новое название/номер, обнаружить ручные правки и устаревший план, применить выбранные изменения без изменения указаний страниц.
4. Новые редакции DOCX: перенести однозначные подтверждённые сопоставления, показать добавленные/удалённые/изменённые упоминания; неоднозначности требуют проверки. Повторное сопоставление не должно терять перенос.
5. История комплектов: неизменяемый ZIP и состав каждой успешной сборки, сравнение с предыдущей сборкой, повторное скачивание с проверкой целостности.
6. Сквозная проверка: вставка, правки, сохранение/открытие, замена DOCX, экспорт Word/PDF, ссылки после перемещения папки. Проверить существующие проекты и сборку дистрибутива.

## Правила реализации

- Проекты и документы остаются на компьютере. HTTPS-панель получает доступ к той же локальной базе в том же процессе.
- Никаких автоматических изменений текста при открытии Word. Обновление запускается пользователем с предварительным просмотром.
- Связь с приложением хранится по постоянному ID, независимо от его номера и имени файла.
- Отсутствующие документы, ручные изменения и несовместимые версии Word показываются явно.
- Исходный DOCX и старые экспорты не перезаписываются.
- Готовый комплект открывается без установленного Word-плагина.
- Совместное редактирование, библиотека дела, OCR и словарь переводов в этот этап не входят.

Ветка `codex/word-workflow`, версия разработки `0.2.0-dev.1`.

В локальной среде установлен Word 16.0.14334. API вставки сносок требует WordApi 1.5 (Windows: 2302 / build 16130+, Mac: 16.70+). Работа прежнего экспорта через Word подтверждена; она не доказывает работоспособность новой панели.

Автоматическая установка доверия к сертификату через `office-addin-dev-certs` не завершилась и была остановлена. HTTPS проверен с явным доверием к созданному CA в тестовом клиенте; доверие системного Word не подтверждено. Проверка интерфейса панели в браузере имитировала только определение Office-хоста, а не вставку/редактирование документа.

Следующий обязательный шаг — [живой тест панели](WORD-WORKFLOW-REVIEW.md) в совместимом Word на Windows и Mac. Пилотный релиз 0.1.2 остаётся действующей версией для команды; новая ветка пока не готова к замене этого релиза.

Проверено 15 сентября: 116 тестов Python и 4 теста JavaScript; сборка интерфейса; браузер 1440×1000 и 390×844, панель 360×980; консоль без ошибок. Через настоящий Word: 7 ссылок / 9 областей PDF, чёрное полужирное начертание; отдельный DOCX с постоянным ID сохранился и повторно открылся, затем был обработан в относительную ссылку. Через HTTP собраны и повторно скачаны две неизменяемые версии ZIP.
