# Этап работы с подачей: план перенесён в OpenSpec

Ранее согласованный этап выпущен в v0.2.0. 29 октября завершён учёт доказательств, требования синхронизированы с базой OpenSpec, задачи архивированы:

- [Опциональная панель Word](../openspec/changes/archive/2026-10-29-optional-word-authoring/proposal.md) — создание и обновление сносок, передача DOCX; [задачи](../openspec/changes/archive/2026-10-29-optional-word-authoring/tasks.md).
- [Редакции DOCX и история комплектов](../openspec/changes/archive/2026-10-29-submission-revisions-and-history/proposal.md) — работают и при обычной загрузке файлов без панели; [задачи](../openspec/changes/archive/2026-10-29-submission-revisions-and-history/tasks.md).
- [Объединение и выпуск](../openspec/changes/archive/2026-10-29-consolidate-release-line/proposal.md) — интеграция с исправлениями rc.5 и проверка пакетов; [задачи](../openspec/changes/archive/2026-10-29-consolidate-release-line/tasks.md).

Панель Word не обязательна для подготовки приложений, сопоставления существующих сносок и сборки комплекта. Основной путь сохраняется без её настройки и сертификата. Конвертер основного PDF — отдельная зависимость.

[Карта продукта](ROADMAP.md) отвечает, что уже есть и куда развивается Open Source Exhibit Manager. [Инструкция живой проверки](WORD-WORKFLOW-REVIEW.md) содержит шаги и результаты Word-тестов; она не заменяет состояния задач OpenSpec.
