# Первый запуск и проверка

BL Exhibit Manager — локальное приложение для подготовки комплектов документов. Данные остаются на компьютере; выбранный текст отправляется Claude/Codex только при разрешённом переводе. Начните с учебных материалов.

## Установка и запуск

1. Скачайте ZIP для своего компьютера: `windows-x64`, `macos-x64` (Intel) или `macos-arm64` (Apple Silicon).
2. Распакуйте **весь ZIP** в отдельную папку. Не запускайте приложение прямо из архива и не переносите отдельно один EXE из папки.
3. Windows: дважды щёлкните `BLExhibitManager.exe` или `Start.cmd`. Mac: откройте `BLExhibitManager.app`. Python и Node устанавливать не нужно.
4. Откроется браузер с локальным приложением. Повторный запуск открывает уже работающий экземпляр.

Пакеты пока без подписи издателя, поэтому Windows или macOS может показать предупреждение при запуске. Если ОС заблокировала запуск, сообщите точный текст и имя скачанного ZIP. Не отключайте защиту системы ради запуска приложения.

## Остановка, обновление, резервная копия

- Закрытие вкладки **не останавливает приложение**. Для остановки запустите `Stop.cmd` (Windows) или `Stop.command` (Mac). Активный перевод сначала завершите либо отмените в переводчике; операция библиотеки также должна завершиться или быть отменена.
- Обновление: сохраните правки, остановите приложение, распакуйте новый ZIP в новую папку и запустите новую версию.
- Проекты хранятся отдельно: `%USERPROFILE%\.bl-exhibit-manager` на Windows, `~/.bl-exhibit-manager` на Mac. Они не удаляются при замене папки приложения.
- Для резервной копии одного проекта нажмите «Архив проекта» → «Сохранить проект». Для переноса выберите скачанный ZIP через «Восстановить проект» на другом компьютере. Существующие проекты не перезаписываются; при совпадении можно создать независимую копию. Архив включает исходники, переводы, решения по ссылкам и историю комплектов. Предел — 8 ГБ распакованных данных / 20 000 файлов; активный перевод сначала завершите или остановите.
- Для копии всех данных при остановленном приложении по-прежнему можно скопировать папку проектов целиком. Папку проектов не удаляйте при обновлении.
- Диагностика запуска: `application.log` в папке проектов. Не публикуйте журналы без проверки на рабочие данные.

Перед обновлением сохраните архив проекта. После первого добавления материала из библиотеки подача получает новый формат: версии 0.3/0.4 его не открывают. Для возврата к старому приложению используйте архив, сделанный до обновления. Дополнительный архив перед первым импортом сохраняется автоматически в подпапке `backups` папки данных. Исходники и прежние комплекты остаются на месте.

## Внешние программы

- Для основного PDF: Microsoft Word на Windows либо LibreOffice на Windows/macOS. На Mac один только Word пока не заменяет LibreOffice для конвертации.
- Для чтения DOCX: настольный Word. Открытие PDF проверено в Adobe Acrobat. Относительные ссылки, включая перенос папки, проверены в SumatraPDF на Windows; для Acrobat перенос отдельно не подтверждён. В PDF24 относительные ссылки с подпапками могут не работать.
- Для перевода установите официальный Claude Code или Codex CLI. В Terminal/PowerShell выполните `claude auth login` или `codex login`, завершите вход и нажмите «Проверить подключение». Аккаунты и подходящая подписка нужны только для автоматического перевода, не для остальной работы.

## Библиотека материалов дела (0.5.0)

Библиотека необязательна. Она хранит оригиналы, проверенные переводы и версии для повторного использования. Каждая подача получает собственные файлы; отключение библиотеки не мешает сборке. Новый перевод сам не запускается.

1. В подаче выберите подготовленное приложение или отметьте несколько строк. Нажмите «Сохранить в библиотеку», создайте библиотеку либо выберите существующую. Раскройте «Реквизиты материала», если нужны категория, дата или метки. Исключите ошибочную строку или явно выберите только оригиналы при черновиках перевода.
2. Нажмите «Проверить состав». Проверьте части и предупреждения. Точное совпадение не объединяется автоматически: можно отказаться от сохранения и использовать найденный материал, сохранить отдельный материал или выбрать его карточку для новой версии. Затем нажмите «Сохранить материалы». Исходная подача сохраняется без изменений.
3. Создайте другую подачу, откройте «Добавить из библиотеки». Найдите материал, откройте карточку и нужную версию. Отметьте материалы, нажмите «Добавить выбранные», назначьте номер, обозначение, папку и имя PDF. «Подготовить из оригинала» переносит перевод и меняет штамп; «Готовый PDF без обработки» сохраняет старый штамп побайтово.
4. Нажмите «Проверить назначения», затем «Добавить в подачу». Просмотрите «Результат» и подтвердите подготовку с новым номером. При неизменных оригинале и выборке проверенный перевод подтверждать заново не требуется. В «Проверка и экспорт» соберите ZIP.
5. Для следующей версии подготовьте изменённый оригинал/перевод в обычной подаче. При сохранении откройте карточку прежнего материала, выберите «Новая версия» и добавьте комментарий. Старые версии и подачи не меняются. В «Сравнить версии» выберите «До» и «После»; состав показывает изменённые части и страницы. У скана доступен обычный визуальный просмотр без OCR; смысл изменений приложение не определяет.
6. В нужной подаче нажмите «Проверить версии материалов». Выберите приложение и версию, нажмите «Сравнить с местной копией». Для конфликтов явно выберите местное значение либо библиотеку и повторите сравнение. Номер, имя PDF, папка и ID сохраняются. «Применить к выбранному приложению» создаёт проверенный архив до изменения; его относительный путь показан в результате. Проверьте только затронутые оформление/перевод/названия ссылок и соберите новый ZIP. Прежний ZIP не меняется. Возврат к v1 выполняется теми же действиями с выбором более ранней версии.

Для первого наполнения без подачи раскройте «Наполнить библиотеку несколькими PDF». Выберите до 100 файлов (до 50 МБ каждый), задайте оригинал / перевод / готовый PDF. Для перевода вручную выберите оригинал, просмотрите PDF и подтвердите соответствие. Повреждённые файлы можно исключить. Проверка состава и явное сохранение публикуют весь выбранный набор; отмена не создаёт частичных материалов.

«Фильтры материалов» объединяются с поиском: категория, дата, метка, язык и наличие перевода. «Где используется» проверяет только доступные подачи в папке данных этого приложения, включая их восстановленные копии. Другие компьютеры и ранее разосланные архивы не входят в справку. Скрытие убирает материал из обычного каталога; через фильтр скрытых его можно вернуть. Файлы и версии сохраняются.

Для переноса раскройте «Архив библиотеки и перенос на другой компьютер». «Сохранить архив библиотеки» включает все материалы и версии. Выбор ZIP сначала проверяет состав и контрольные суммы. При совпадении библиотеки доступны отмена и независимая копия: копия получает новые источники и не обновляет прежние подачи. Архив подачи и архив библиотеки — разные типы файлов; для самостоятельной работы достаточно архива подачи. После восстановления соответствующей библиотеки снова доступны её версии. Предел архива — 8 ГБ распакованных данных / 20 000 записей.

При отмене, нехватке места или устаревшем выборе данные не публикуются частично. Если приложение остановилось, повторите проверку состава; уже выполненное применение той же операции не создаёт дубликатов. После изменения данных в другом окне предварительную проверку необходимо повторить.

## Проверка обычного комплекта

Учебный комплект создаётся через «Новая» → «Новый учебный комплект» или «Открыть учебный комплект» при первом запуске. Материалы вымышлены и генерируются локально.

1. Создайте учебный комплект. Проверьте загрузку, предпросмотр, номера, общие настройки и фрагмент страницы.
2. При необходимости откройте переводчик. Выберите страницы, обозначьте сноски, проверьте отправляемый текст и сами запустите перевод. «Вход найден» ещё не подтверждает доступ к модели.
3. Измените слово перевода, сохраните, закройте и откройте переводчик. Проверьте сохранение правки и PDF, включая сноски/колонтитулы внизу. Подтвердите и прикрепите перевод.
4. Сопоставьте сноски основного Word с приложениями. Учебный RLA-99 намеренно отсутствует: добавьте предложенный файл и задайте номер 99.
5. Устраните ошибки, подготовьте основной PDF и соберите ZIP. Распакуйте весь комплект, откройте DOCX/PDF и перейдите по ссылкам. В Word — Ctrl+щелчок по тексту сноски внизу страницы.
6. Переместите всю распакованную папку и повторите переходы. Остановите/запустите приложение и убедитесь, что проект сохранён.

В Word нажимайте ссылку в тексте сноски внизу страницы, а не во всплывающей подсказке. Переносите всю распакованную папку Submission, сохраняя её структуру.

## Панель Word, новые редакции и история

Панель Word экспериментальная и необязательная: она помогает создавать сноски и обновлять названия прямо в Word.

Новый путь подключения проверен в настоящем Word на Windows. Пакеты и платформенные операции macOS проверяются автоматически; новое подключение внутри Word на Mac и отдельная чистая установка Windows пока не подтверждены. Замечания можно передавать по мере использования.

Для подключения откройте «Помощь и настройка» → «Подключить панель» → «Разрешить и подключить». Подтвердите запрос системы, если он появится. Приложение само подготовит соединение, зарегистрирует панель и откроет новый учебный документ в Word. Дождитесь панели и выберите учебную подачу. HTTPS и связь с Word показаны отдельно. При отказе или ошибке можно отменить настройку и продолжить без панели.

Кнопка «Открыть новый учебный документ в Word» каждый раз создаёт отдельный учебный DOCX с панелью. Чтобы продолжить свой документ, откройте его в Word обычным способом. Успешная настройка сохраняется после остановки и повторного запуска приложения; повторное доверие при неизменном сертификате не требуется.

Если после удаления подключение требует обновления локального сертификата Windows, приложение выполнит это автоматически с обычным системным подтверждением. Если Word уже открыт, появится следующий шаг: сохраните документы и закройте все окна Word, затем нажмите «Открыть новый учебный документ в Word». Приложение запустит Word заново; самостоятельно закрывать ваши документы оно не будет.

Если обнаружено подключение к прежней копии приложения, выберите «Обновить подключение» → «Разрешить и обновить». Word переключится на эту копию. Прежняя регистрация сохраняется для восстановления при удалении нового подключения; старые документы и сертификаты не меняются.

Нужен совместимый настольный Word с WordApi 1.5 (Microsoft 365 либо Office 2024/LTSC); ограничения организации сохраняются. Подробности — во встроенной инструкции. Python, Node и исходники не нужны. Обычная загрузка DOCX/PDF, подготовка и экспорт работают без панели.

В панели можно создать сноску, добавить ещё одну ссылку в существующую сноску, выбрать полное или короткое название и отдельно указать страницу/параграф. После изменения номера или названия в приложении нажмите «Проверить ссылки» и примените выбранные обновления. Ручные изменения текста автоматически не перезаписываются. Единообразное оформление обозначения и названия сохраняется; при смешанном оформлении внутри названия панель просит обновить ссылку вручную. Для вставки и обновления отключите запись исправлений в Word.

При замене основного DOCX приложение показывает отчёт о новой редакции. Подтверждённые решения, включая «Без файла», ручные ссылки и исключения, сохраняются для неизменных однозначно найденных фрагментов, даже если номер сноски поменялся. Дублирующиеся или изменённые фрагменты требуют проверки. Перед сборкой подтвердите сопоставление новой редакции.

В разделе «Проверка и экспорт» доступна «История комплектов»: состав, изменения и повторное скачивание прежнего ZIP. Старые комплекты не меняются при редактировании проекта. История хранится на этом компьютере вместе с проектом и **не заменяет резервную копию проекта**.

## Подключение и использование перевода

Установите официальный [Claude Code](https://code.claude.com/docs/en/quickstart) или [Codex CLI](https://developers.openai.com/codex/cli). В Terminal/PowerShell выполните `claude auth login` или `codex login`, завершите вход и нажмите «Проверить подключение».

«Вход найден» подтверждает авторизацию, но не доступ к переводу: для этого выполните пробный перевод небольшого текста. Ошибки подписки, лимитов и неполные ответы показываются в приложении. Автоматический перевод проверен на Windows; проверка на Mac ещё предстоит.

Выберите «Через свою подписку Claude / Codex» → «Открыть переводчик». Укажите страницы или области, задайте зоны сносок и проверьте «Текст для отправки». После разрешения отправки и завершения перевода проверьте текст и PDF, затем подтвердите и прикрепите перевод. Правки черновика не заменяют уже прикреплённый PDF автоматически.

Пароли и токены остаются в официальном CLI. API-ключи не нужны. Отправляется только показанный и разрешённый вами текст; сам PDF, соседние проекты и имена исходных файлов не передаются. Использование Claude и Codex регулируется условиями соответствующего провайдера.

## Обновление старых проектов

После обновления с версии 0.1.0 проекты сохраняют прежнюю полосу над страницей. Для штампа без сдвига содержимого откройте «Оформление» и выберите «В полях исходной страницы». В новых проектах этот режим включён сразу.

Чтобы расширить старые ссылки на постоянную часть названия, повторите «Сопоставить ссылки», проверьте границы, подтвердите и заново подготовьте основной PDF. Жирным выделяется только обозначение приложения; начертание остального названия сохраняется. Сохранённые ранее файлы автоматически не меняются — пересоберите комплект.

## Сохранение и восстановление проекта

С версии 0.3.0 проект можно перенести на другой компьютер или сохранить отдельно от приложения:

1. В верхней строке приложения выберите нужный проект в поле «Проект» и нажмите «Архив проекта» рядом с кнопкой «Новая».
2. Нажмите «Сохранить проект». Скачанный ZIP содержит исходные документы, настройки, сопоставления, переводы и историю комплектов. Храните его отдельно от рабочей папки приложения.
3. Для восстановления откройте «Архив проекта» → «Восстановить проект» и выберите сохранённый ZIP.
4. Проверьте показанный состав и подтвердите восстановление. Если проект уже существует, можно восстановить независимую копию; существующий проект не перезаписывается.

Предел архива — 8 ГБ распакованных данных и 20 000 файлов. Настройки подключения, сертификат панели и входы в сервисы не переносятся. Для самого восстановления панель Word, конвертер и переводчик не нужны.

Если используете управляемые ссылки панели Word, откройте копию DOCX и выберите восстановленную копию проекта в панели. Нажмите «Проверить ссылки» и примените предложенные обновления: ссылки будут относиться к копии проекта. Исходный DOCX и ранее собранные ZIP не изменяются.

## Сообщение об ошибке

Укажите ОС/архитектуру, версию приложения из `build-info.json`, шаги воспроизведения и текст ошибки. В публичный GitHub не прикладывайте конфиденциальные документы, токены или папку проектов. Для воспроизведения используйте вымышленный пример.

## Первый запуск и помощь

На первом экране можно создать подачу, открыть учебный комплект или восстановить архив проекта. В учебном комплекте сначала выберите PDF, проверьте его результат и подтвердите подготовку. Во вкладке «Ссылки в Word» сопоставьте упоминания; намеренно отсутствующий RLA-99 можно скачать из подсказки внизу этой вкладки. После подтверждения сносок откройте «Проверка и экспорт» и соберите ZIP. Для преобразования основного DOCX в PDF нужен конвертер.

В существующей работе приложение сразу открывает последний проект. Кнопка «Помощь и настройка» всегда доступна сверху: там можно проверить конвертер и отдельно каждый переводчик. Проверки CLI ограничены по времени и не обращаются к модели. При ошибке нажмите «Показать сводку диагностики», просмотрите и скопируйте её в обращение. Сводка не содержит документов, путей или данных входа; автоматически ничего не отправляется.
