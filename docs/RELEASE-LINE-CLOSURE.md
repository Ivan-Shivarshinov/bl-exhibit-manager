# Закрытие подготовительных задач перед 0.6.0

29 октября 2026. База: v0.5.1 (`698b942`), аудит/план `8f0bafb`. Эта работа не реализует перечень приложений и не создаёт новый публичный релиз.

## Форма создания библиотеки

CI тега `39927092607` остановился до POST: после `fill` имя пустое, каталог успешно загружен. В `MaterialLibrary.jsx` один `loading` менялся двумя независимыми операциями: первоначальным списком библиотек и материалами выбранной библиотеки. Первая снимала блокировку поля, следующая снова устанавливала её; готовность поля зависела от постороннего запроса. Точный момент потери события ввода в старом CI не записан; это не трасса доказанного сбоя Playwright.

Исправление `ec480a6` разделяет эти состояния. Создание ждёт первоначальный список и собственную запись, но не каталог другой библиотеки. Смена состояния каталога больше не отключает поле/кнопку создания. Таймаут старого UI-теста не увеличен, автоматический повтор не добавлен.

`node --test scripts/library_loading_ui.cjs` использует настоящий React-компонент и Chromium с управляемыми HTTP-ответами, без данных пользователя:

| Сценарий | До изменения | После |
|---|---|---|
| Ввод/создание при задержанном каталоге | Поле недоступно, отказ проверки | Один POST до завершения каталога |
| Завершение каталога после ввода | Отказ на недоступном поле | Имя сохраняется и отправляется один раз |
| Ошибка каталога/создания | Отказ на недоступном поле | Имя остаётся для следующей попытки |
| Первая библиотека, пустой список | Успешно | Успешно |

Новая проверка включена в CI трёх платформ. Полный `ready_pdf_ui.cjs` дополнительно проходит загрузку PDF → ZIP → сохранение в новую библиотеку → независимый импорт → повторный ZIP и сверку исходников. Полный [CI 40833618483](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/actions/runs/40833618483) для `ec480a6` завершился успешно с первой попытки: три нативных пакета и три задания взаимного переноса архивов. На каждой платформе прошли 303 Python-теста, 25 JS-тестов и четыре новые браузерные проверки; на обоих Mac — отдельные реальные проверки LibreOffice 26.8.0.3. Панель Word в CI имитируется, нового живого прогона Office.js не было.
