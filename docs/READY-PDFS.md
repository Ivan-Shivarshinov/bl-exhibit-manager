# Готовые PDF без повторного оформления

Начиная с версии 0.1.3-rc.3 можно загрузить уже оформленные приложения и сразу перейти к ссылкам в Word.

## Новые файлы

1. В разделе «Документы» нажмите **«Добавить готовые PDF»** и выберите все нужные файлы.
2. Нажмите **«К ссылкам в Word»**, загрузите основной DOCX и выполните сопоставление.
3. Проверьте сноски, подтвердите сопоставление и соберите комплект в разделе «Проверка и экспорт».

Названия загруженных файлов используются для сопоставления. Например, `Annex 47.pdf` можно сопоставить с упоминанием «Annex 47» без повторного назначения номера.

## Уже загруженные документы

1. Выделите нужные строки слева. Флажок над таблицей выбирает все документы текущего фильтра; очистите поиск, чтобы выбрать весь список.
2. Нажмите **«Использовать выбранные без обработки»**.
3. Перейдите к ссылкам в Word. Если они уже сопоставлены, выбор файлов сохранится.

Каждый выбранный исходный PDF войдёт в комплект целиком, без изменения содержимого, размера страниц и существующих штампов. Выбор отдельных страниц и фрагментов не применяется. Подтверждать оформление каждого PDF не нужно. Проверки имён, исходных файлов и сопоставления ссылок сохраняются.

Если прикреплён отдельный перевод, операция сообщит об этом и не изменит выбранные документы. Снимите выбор этого документа либо открепите перевод, если в комплект должен войти только исходный PDF.

Для возврата к оформлению выберите у документа «Подготовить приложение» и сохраните настройки. Его результат снова потребуется проверить и подтвердить.
