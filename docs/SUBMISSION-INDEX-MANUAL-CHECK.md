# Проверка переходов в перечне 0.6.0

Остаётся подтвердить именно нажатие относительных ссылок в настольных программах. Автоматически уже проверяются точные цели, байты файлов, перенос папки и восстановление архива; рендер Word/LibreOffice проверяется отдельно. Установка панели Word для этого сценария не нужна.

На этом ПК доступны Microsoft Word 16.0.17928.20148, SumatraPDF 3.5.2 и PDF24. Отказ `#` в SumatraPDF 3.5.2 уже воспроизведён, повторять его не требуется. Для сравнения нужна 3.6.1; официальный сервер её загрузки при фоновой работе ответил HTTP 403. Не устанавливайте обновление поверх рабочей версии и не меняйте ассоциации файлов ради проверки: достаточно отдельной portable-копии, если она доступна. Отсутствие этой программы не записывается как успешная проверка.

Новые искусственные файлы из исправленного Windows-пакета готовятся в `output/submission-index-links-20261029/native-viewer-case/`. Их наличие и исходный ZIP/SHA-256 подтверждает `fixture-report.json`; без этого отчёта комплект ещё не готов. В `Before move/Submission/` — `Exhibit index.docx`, `Exhibit index.pdf`, пустая проверочная `Word reference.docx` и шесть различных PDF. Побайтово одинаковая копия — `После переноса/Submission/`. Рабочих материалов в них нет.

1. Сначала сравните запись с Word: откройте `Word reference.docx`, создайте в Word ссылку на лежащий рядом `Материалы/Annex 2.pdf`, сохраните документ и откройте ссылку. Ожидается `SYNTHETIC TARGET 2`. Сравните hyperlink relationship из сохранённого Word DOCX с соответствующей ссылкой перечня; не используйте частные документы для контроля.
2. Откройте `Before move/Submission/Exhibit index.docx` в Word. Нажмите Ctrl и щёлкните «Target 12», затем «Target 13». Ожидаются соответственно `Annex 12%.pdf` и `Annex 13%.pdf` из вложенной `Материалы # 50%/O'Brien & Co/`; на страницах видны разные `SYNTHETIC TARGET 12/13`. «Target 2» отдельно проверяет папку с кириллицей без `#`.
3. Откройте `Exhibit index.pdf` в SumatraPDF 3.6.1 и доступном другом настольном просмотрщике, не меняя системную безопасность. Нажмите «Target 12» и «Target 13». Ожидаются соответствующие разные PDF; соседняя ссылка не должна вести к предыдущему приложению. Запишите точные версии и отдельный результат каждой программы.
4. Повторите два соседних перехода из DOCX/PDF в `После переноса/Submission/`. Ожидаются те же документы из перенесённой папки без BL Exhibit Manager. Сверьте пути открытых файлов: ссылка не должна возвращать к старой копии. Не переносите только сам перечень.

Для оставшейся ручной проверки нужны только эти шаги и точные версии программ. Если переход не сработал, зафиксируйте выбранную строку и текст сообщения. Установку панели, конвертацию основного документа, библиотеку и прежние подтверждённые сценарии повторять не нужно. Для управления окнами агентом требуется отдельное разрешение; после короткой проверки управление прекращается до любой фоновой доработки или сборки.

До подтверждения этих переходов задача 3.5 и окончательное архивирование изменения не отмечаются завершёнными.

**Word уже подтверждён:** создание контрольной ссылки, открытие Annex 12/13 и перенос; эти шаги повторять не нужно. PDF24 11.30.1 не прошёл простой контроль, поэтому он не используется как подтверждение.

Осталась отдельная SumatraPDF 3.6.1: `output/submission-index-links-20261029/tools/SumatraPDF-3.6.1-64.exe` (официальная portable-копия; установленную 3.5.2 заменять не нужно). Откройте в ней `Before move/Submission/Exhibit index.pdf`, нажмите Target 12 и Target 13, затем повторите из `После переноса/Submission/Exhibit index.pdf`. Должны открыться разные `SYNTHETIC TARGET 12/13` именно из соответствующих папок, включая кириллицу, `#` и `%`. Без успешного результата этого прохода новые пакеты не принимаются к выпуску.
