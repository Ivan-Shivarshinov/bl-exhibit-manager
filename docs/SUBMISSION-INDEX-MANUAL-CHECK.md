## Только для добровольного воспроизведения

Искусственный комплект: `output/submission-index-links-20261029/native-viewer-case/`. Рабочих материалов в нём нет.

1. Откройте `Before move/Submission/Exhibit index.docx` в настольном Word. Откройте ссылки Target 12 и Target 13. Ожидаются разные PDF с `SYNTHETIC TARGET 12/13` из `Материалы # 50%/O'Brien & Co/`.
2. Откройте соседний `Exhibit index.pdf` в SumatraPDF 3.6.1. Нажмите те же две ссылки. Ожидаются соответственно Annex 12%.pdf и Annex 13%.pdf.
3. Повторите переходы из `После переноса/Submission/`. В свойствах открытых PDF должен быть новый корень, а не Before move. Передавайте папку Submission целиком; сами перечни и PDF менять не нужно.

SumatraPDF 3.5.2 с `#` не совместим; PDF24 Reader 11.30.1 переходы не выполнил. Общую установку панели, библиотеку и конвертацию основного документа повторять не требуется.
