## Адресные исправления при проверке

- Номер при наложении мог оказаться вне правого края: теперь место рассчитывается для номера и возврата вместе, проверяется весь прямоугольник, regression проверяет реальные координаты символов.
- Добавление искусственного родителя к полям приводило к исчезновению их изображения в PDFium. Теперь существующие верхние поля получают отдельные имена без нового родителя. Поля с одинаковыми исходными именами независимы; для 0/90/180/270° изображение исходной части с полем побайтово совпадает с растром в томе.
- Старые backup fixtures содержали произвольные байты вместо ZIP. Они заменены настоящими искусственными ZIP без ослабления проверки истории.
- Windows CI воспроизвёл одинаковое время двух быстрых экспортов: старый комплект мог оказаться первым в истории. Новые записи получают строго возрастающее время в пределах подачи, в том числе при одинаковом такте часов; regression фиксирует часы без искусственной задержки.
- Нативная Office-проверка выявила отказ сохранения обычного перечня после обновления проекта до схемы 4. Настройки перечня теперь повышают формат до минимально нужного, сохраняя уже более новый; frozen API проверяет индекс после перенумерации и вместе с томами.

## Предварительно объявленная нагрузка

`scripts/volume_stress.py`: отдельный процесс для каждого профиля, предел RSS 2,5 ГБ; время — 30/180/600 секунд. Готовые большие PDF не записываются на диск. Локально Windows: 6 страниц/3 материала — 0,125 с и 58 МиБ; 500/50 — 3,985 с и 165 МиБ; 10 000/1 000 — 104,078 с и 711 МиБ, 20 томов, 330 315 452 байта результата. Это искусственная нагрузка, не гарантия времени для любого PDF/компьютера. Нативные измерения фиксируются отдельными JSON.

Программные предохранители: 2 000 материалов, 512 МБ входных подготовленных PDF, 10 000 исходных и 20 000 итоговых страниц, 100 томов, 1 ГБ PDF-результата. Проверяются отмена, устаревание, слишком большой одиночный материал, ошибка записи и восстановление после остановки. Единственный материал не разрезается автоматически.

Локально на Windows: общий набор 390 Python (1 skip) / 34 JS, Vite и строгая OpenSpec — успешно. Chromium также проверяет собственный порядок, интерактивный переход между томами/возврат, отмену 1000 страниц без истории и повтор.
