# BL Exhibit Manager

Приложение с открытым исходным кодом для подготовки судебных и арбитражных приложений: библиотека материалов дела, оформление и нумерация PDF, переводы и ссылки из документа Word. Результат — переносимый ZIP с приложениями и, при наличии основного документа, DOCX и PDF.

Работает локально на Windows и macOS. Внешний сервер не нужен: приложение запускается на вашем компьютере, а интерфейс открывается в браузере. Для автоматического перевода используются выбранные вами внешние сервисы.

**Текущая версия — [0.5.0](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/releases/tag/v0.5.0)**: библиотека материалов дела и исправления работы с готовыми PDF, ссылками и разделителями сносок.

**Версия для пилотного использования.** Перед подачей проверьте готовые документы и ссылки.

## Скачать и запустить

1. Откройте [последний релиз](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/releases/latest) и скачайте ZIP для Windows, Mac с Apple Silicon или Mac с Intel.
2. Распакуйте архив целиком в отдельную папку.
3. Запустите `Start.cmd` на Windows или `BLExhibitManager.app` на Mac. Приложение откроется в браузере; Python и Node устанавливать не нужно.

Для остановки используйте `Stop.cmd` или `Stop.command`: закрытие вкладки не останавливает приложение. Перед обновлением сохраните архив проекта. Остановите прежнюю версию и распакуйте новый ZIP в отдельную папку — проекты сохранятся. После добавления материала из библиотеки открывайте подачу в версии 0.5.0 или новее; для возврата к старой версии используйте архив, сохранённый до обновления.

Приложение пока без подписи издателя, поэтому ОС может показать предупреждение при первом запуске. Подробнее: [установка, обновление и резервная копия](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/blob/v0.5.0/docs/PILOT.md).

## Возможности

- Библиотеки дел: оригиналы, проверенные переводы и готовые PDF для повторного использования в разных подачах без повторного перевода.
- Версии материалов и визуальное сравнение PDF. Обновление применяется только к выбранной подаче; местные правки можно сохранить.
- Массовое добавление материалов, поиск, категории, даты, метки, фильтры и поиск точных дубликатов. Просмотр, в каких локальных подачах используется материал.
- Архивы библиотек со всеми версиями; каждая подача остаётся самостоятельной и работает без доступной библиотеки.
- Готовые PDF без переоформления, включая файлы с формами и электронными подписями: содержимое сохраняется, имена и папки можно менять.
- Оформление PDF: штампы Exhibit/Annex, номера, имена файлов и папки, в том числе массовые настройки.
- Обозначения с префиксом и без него: `Exhibit RLA-31`, `Annex 1`, `Exhibit 1`.
- Выбор страниц и фрагментов; штампы в полях без сдвига содержимого или в отдельной полосе над страницей.
- Перевод выбранного текста через **Claude или Codex**, сверка с оригиналом и редактирование. Можно прикрепить готовый перевод PDF.
- Разметка сносок и колонтитулов для перевода с размещением на соответствующих страницах.
- Ссылки из существующих сносок Word на PDF-приложения. Кликабельна постоянная часть названия; границы можно исправить вручную. Ссылки чёрные без подчёркивания; жирным выделяется обозначение приложения, остальное начертание сохраняется.
- Опциональная панель Word для создания сносок и обновления названий. Обычная загрузка DOCX работает без панели и её настройки.
- Приложения в списках выбора отсортированы по возрастанию номера.
- Сохранение отступов разделителей сносок при конвертации через LibreOffice, предупреждения о шрифтах и инструкция по размещению блока подписи.
- Перенос однозначных сопоставлений при замене DOCX и история ранее собранных комплектов.
- Экспорт комплекта с переводами перед оригиналами и относительными ссылками. Переносите распакованную папку целиком, сохраняя её структуру.

Библиотека и экспериментальная панель Word необязательны. Панель подключается через «Помощь и настройка» → «Подключить панель» с вашего согласия, по [встроенной инструкции](exhibit/assets/WORD-SETUP.txt). Обычная загрузка DOCX/PDF, подготовка приложений и экспорт работают без панели. Приложения можно готовить и без основного документа.

## Что потребуется

| Задача | Требования |
|---|---|
| Запуск | Windows 11 или macOS 13+, Intel / Apple Silicon |
| Подготовка основного PDF | Microsoft Word или LibreOffice на Windows; LibreOffice на Mac |
| Опциональная панель Word | Настольный Microsoft Word с поддержкой WordApi 1.5 |
| Автоматический перевод | Claude Code или Codex CLI и аккаунт с подходящей подпиской |

Внешние программы устанавливаются отдельно. Подписка нужна только для автоматического перевода.

Работа относительных ссылок зависит от PDF-просмотрщика и его настроек безопасности. Переносите комплект целиком и проверяйте переходы после распаковки. **В PDF24 Reader относительные ссылки могут не работать.**

## Первый комплект

1. Создайте проект и добавьте PDF или выберите материалы из библиотеки дела. При необходимости загрузите основной DOCX с уже существующими сносками.
2. Задайте номера, имена и оформление приложений. Выберите страницы или фрагменты, при необходимости подготовьте перевод.
3. Проверьте результат и подтвердите подготовку документов.
4. Если загружен основной DOCX, в «Ссылки в Word» сопоставьте упоминания с приложениями и проверьте границы ссылок.
5. В «Проверка и экспорт» устраните ошибки, подготовьте основной PDF, если загружен DOCX, и скачайте ZIP.
6. Распакуйте весь комплект и проверьте документы и переходы по ссылкам.

Начать можно со встроенного учебного комплекта. [Подробная инструкция](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/blob/v0.5.0/docs/PILOT.md) описывает перевод, учебный пример и проверку результата.

## Данные и приватность

Исходные файлы сохраняются отдельно. Проекты хранятся на вашем компьютере: `%USERPROFILE%\.bl-exhibit-manager` на Windows и `~/.bl-exhibit-manager` на Mac. Кнопка «Архив проекта» позволяет сохранить проект целиком и восстановить его на другом компьютере, включая переводы, сопоставления и историю комплектов. Существующий проект при восстановлении не перезаписывается. Библиотека переносится отдельным архивом со всеми версиями; архив подачи содержит всё необходимое для работы с самой подачей.

При переводе провайдеру отправляется только показанный и разрешённый вами текст. Сам PDF не отправляется. Авторизация выполняется через официальный CLI Claude или Codex; API-ключи не требуются. Облачной синхронизации и телеметрии нет.

Не прикладывайте конфиденциальные документы, токены или папку проектов к публичным Issues. Для сообщения об ошибке используйте вымышленный пример и укажите версию приложения, ОС и шаги воспроизведения.

## Ограничения

- Входные форматы: PDF для приложений и переводов, DOCX для основного документа. До 50 МБ на файл и 1000 страниц на PDF.
- OCR и автоматический перевод сканов, печатей и изображений не поддерживаются. Можно прикрепить готовый перевод PDF.
- До 120 000 выбранных знаков за один перевод; одновременно выполняется один перевод. Правки черновика нужно подтвердить и прикрепить заново, чтобы они попали в комплект.
- Сноски для перевода размечаются вручную. Сложные таблицы, оформление надстрочных знаков и переходы к сноскам автоматически не восстанавливаются.
- Выделенные прямоугольные фрагменты становятся изображениями и теряют поиск по тексту.
- PDF с формами и электронными подписями поддерживаются как готовые файлы, без переоформления. Действительность электронной подписи приложение не проверяет. Защищённые PDF, DOCX Strict, макросы и некоторые сложные элементы сносок не поддерживаются.
- Word и LibreOffice могут по-разному разбивать документ на страницы. При подготовке основного PDF проверяйте шрифты и вёрстку; если приложение не подтверждает сохранность ссылок, выдача PDF и ZIP блокируется.
- Очень большие комплекты могут потребовать значительного объёма памяти.
