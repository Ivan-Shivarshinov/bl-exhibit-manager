# BL Exhibit Manager

Локальный инструмент для подготовки судебных приложений: PDF, переводы, фрагменты, нумерация и основной DOCX/PDF с относительными ссылками.

**Статус: версия для пилотного тестирования.** Основной процесс проверен на Windows. Дистрибутив без установки Python/Node готовится; macOS и успешный перевод через Claude ещё требуют проверки. Пользователь проверяет выходные документы перед подачей.

## Возможности

- Оригиналы и готовые переводы PDF; исходники сохраняются отдельно.
- Перевод выбранных страниц и областей через личную подписку **Claude или Codex**, проверка и редактирование рядом с оригиналом.
- Отдельный перевод сносок и колонтитулов с размещением на соответствующей странице; границу сносок задаёт пользователь.
- Выбор страниц и прямоугольных фрагментов, отметки пропусков, штампы Exhibit/Annex и языковые пометки.
- Настройки подачи, папки и документа; массовое оформление, номера и имена с проверкой конфликтов.
- Сопоставление существующих сносок DOCX с приложениями, ручное разрешение неоднозначностей, относительные ссылки.
- ZIP: перевод перед оригиналом, PDF приложений, основной DOCX и основной PDF. Приложения можно готовить без основного документа.
- Режим «Использовать без обработки» сохраняет готовый PDF байт в байт.

## Поддерживаемые среды

| Среда | Статус и требования |
|---|---|
| Windows 11 | Основной процесс проверен. Для основного PDF нужен установленный Microsoft Word либо LibreOffice. |
| macOS 13+, Intel / Apple Silicon | Равноправная целевая платформа; требуется реальное тестирование. Основной PDF текущий адаптер создаёт через LibreOffice; DOCX открывается в desktop Word. |
| PDF-просмотрщик | Относительные ссылки проверены в SumatraPDF на Windows, включая перенос папки. PDF24 Reader не прошёл эту проверку. Другие просмотрщики требуют проверки. |

Word, LibreOffice, Claude Code и Codex CLI устанавливаются отдельно.

## Запуск из исходников

Нужны Python 3.12 и Node.js 22.12+; Node используется только при сборке интерфейса.

Windows, PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
npm.cmd ci --prefix web
npm.cmd run build --prefix web
.\Start.cmd
```

macOS, Terminal в папке проекта:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
npm ci --prefix web
npm run build --prefix web
sh Start.command
```

Откроется `http://127.0.0.1:8765`. Повторный запуск использует работающий сервер. Закрытие вкладки не завершает сервер. Для диагностического запуска с остановкой через Ctrl+C:

```powershell
.\.venv\Scripts\python.exe -m uvicorn exhibit.app:app --host 127.0.0.1 --port 8765
```

На macOS используйте `.venv/bin/python`. Не публикуйте локальный сервер в интернете.

## Первый комплект

1. Нажмите «Новая» → «Новый учебный комплект» или «Открыть учебный комплект» при первом запуске. Материалы вымышлены и генерируются локально.
2. Настройте приложения: номер, имя, папку, оформление, перевод при необходимости. Проверьте «Результат» и подтвердите подготовку.
3. Для автоматического перевода выберите «Через свою подписку Claude / Codex» → «Открыть переводчик». Выберите страницы/области, задайте зоны сносок, проверьте «Текст для отправки», затем разрешите отправку. После перевода проверьте текст и PDF и прикрепите подтверждённый перевод.
4. В «Ссылки в Word» сопоставьте документы со сносками. Учебный RLA-99 намеренно отсутствует: загрузите предложенный в интерфейсе файл и задайте ему номер 99.
5. В «Проверка и экспорт» устраните блокирующие ошибки, подготовьте основной PDF и скачайте ZIP.
6. Распакуйте **всю папку Submission**. Откройте DOCX в Word, а PDF — в поддерживаемом просмотрщике. В Word нажимайте Ctrl+щелчок по ссылке в тексте сноски внизу страницы, а не по всплывающей подсказке. После перемещения всей папки повторите переходы.

## Подключение перевода

Установите официальный [Claude Code](https://code.claude.com/docs/en/quickstart) или [Codex CLI](https://developers.openai.com/codex/cli). В терминале выполните `claude auth login` либо `codex login`, завершите вход через подходящую подписку и нажмите «Проверить подключение».

«Вход найден» подтверждает авторизацию, но не доступность модельного запроса. Подписку проверяет отдельный пробный перевод. Реальные запросы Codex проверены; успешный запрос Claude пока не подтверждён. Ошибки подписки, лимитов и неполные ответы показаны в приложении.

Пароли и токены остаются в официальном CLI. API-ключи не требуются. В запрос уходит только показанный и разрешённый пользователем текст; PDF-файл, соседние проекты и имена исходных файлов не передаются. Компоненты провайдера и использование подписок регулируются их собственными условиями.

## Данные и ограничения

Проекты хранятся в `%USERPROFILE%\.bl-exhibit-manager` на Windows и `~/.bl-exhibit-manager` на macOS, отдельно от приложения. При остановленном сервере эту папку можно скопировать целиком для резервного сохранения. `EXHIBIT_DATA_DIR` позволяет выбрать другую папку. Не запускайте несколько серверов с одной папкой данных.

Исходники проверяются по SHA-256; изменения сохраняются атомарно. Документы отправляются провайдеру только при явно разрешённом переводе. Облачного кабинета, синхронизации и телеметрии нет. **Не прикладывайте рабочие документы, токены или папку проектов к публичным Issues.** Используйте вымышленные материалы для воспроизведения ошибок.

- PDF приложений/переводов и DOCX основного документа; до 50 МБ на файл, 1000 страниц на PDF.
- OCR, автоматический перевод сканов, печатей и изображений не поддерживаются. Готовый перевод PDF можно прикрепить вручную.
- До 120 000 выбранных знаков на перевод, части до 6000 знаков, один активный перевод. Правки черновика не заменяют прикреплённый PDF без подтверждения.
- Сноски размечаются вручную. Сложные таблицы, исходное оформление надстрочных знаков и интерактивные переходы к сноскам автоматически не восстанавливаются. Переполнение страницы блокирует PDF без обрезания текста.
- Прямоугольные фрагменты содержат только выбранные пиксели в 300 dpi; поиск по тексту в них теряется.
- Защищённые PDF, формы/подписи, DOCX Strict, макросы, подписи и некоторые сложные элементы в сносках не поддерживаются. Новые сноски Word не создаются, их текст не переписывается.
- Экспорт создаётся в памяти. Нагрузка проверена на 100 небольших PDF, не на сотнях тяжёлых сканов.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npm.cmd run build --prefix web
```

На macOS замените пути Python и `npm.cmd` на `.venv/bin/python` и `npm`. Тесты используют временные папки и явные имитации моделей, не расходуют подписки. Word/LibreOffice, реальный вход и пользовательские переходы проверяются отдельно.

Структура: `exhibit/` — Python/FastAPI и документы; `web/` — React/Vite; `tests/` — тесты; `scripts/` — запуск и дополнительные проверки. Учебные материалы создаёт `python -m exhibit.samples`; результаты, документы, окружения и локальные настройки исключены из Git.

До самостоятельного пилота: дистрибутив, запуск/остановка/обновление и проверка установки. Командная приёмка: macOS, подходящая подписка Claude и обезличенный рабочий комплект с эталоном.
