# BL Exhibit Manager

Локальное приложение для подготовки судебных приложений: оформление и нумерация PDF, переводы и ссылки из основного документа Word. Результат — ZIP с приложениями, основным DOCX и PDF.

**Версия для пилотного использования.** Перед подачей проверьте готовые документы и ссылки.

## Скачать и запустить

1. В [Releases](https://github.com/Ivan-Shivarshinov/bl-exhibit-manager/releases) выберите версию и скачайте ZIP для Windows, Mac с Apple Silicon или Mac с Intel.
2. Распакуйте архив целиком в отдельную папку.
3. Запустите `Start.cmd` на Windows или `Start.command` на Mac. Приложение откроется в браузере; Python и Node устанавливать не нужно.

Для остановки используйте `Stop.cmd` или `Stop.command`: закрытие вкладки не останавливает приложение. При обновлении остановите прежнюю версию и распакуйте новый ZIP в отдельную папку — проекты сохранятся.

Приложение пока без подписи издателя, поэтому ОС может показать предупреждение при первом запуске. Подробнее: [установка, обновление и резервная копия](docs/PILOT.md).

## Возможности

- Оформление PDF: штампы Exhibit/Annex, номера, имена файлов и папки, в том числе массовые настройки.
- Обозначения с префиксом и без него: `Exhibit RLA-31`, `Annex 1`, `Exhibit 1`.
- Выбор страниц и фрагментов; штампы в полях без сдвига содержимого или в отдельной полосе над страницей.
- Перевод выбранного текста через **Claude или Codex**, сверка с оригиналом и редактирование. Можно прикрепить готовый перевод PDF.
- Разметка сносок и колонтитулов для перевода с размещением на соответствующих страницах.
- Ссылки из существующих сносок Word на PDF-приложения. Кликабельна постоянная часть названия; границы можно исправить вручную. Ссылки чёрные без подчёркивания; жирным выделяется обозначение приложения, остальное начертание сохраняется.
- Опциональная панель Word для создания сносок и обновления названий. Обычная загрузка DOCX работает без панели и её настройки.
- Перенос однозначных сопоставлений при замене DOCX и история ранее собранных комплектов.
- Экспорт комплекта с переводами перед оригиналами и относительными ссылками. Переносите распакованную папку целиком, сохраняя её структуру.

Панель, новые редакции и история доступны в этой ветке разработки; проверяйте состав выбранного релиза. Приложения можно готовить без основного документа. Режим «Использовать без обработки» сохраняет готовый PDF без изменений.

## Что потребуется

| Задача | Требования |
|---|---|
| Запуск | Windows 11 или macOS 13+, Intel / Apple Silicon |
| Подготовка основного PDF | Microsoft Word или LibreOffice на Windows; LibreOffice на Mac |
| Работа с DOCX | Настольный Microsoft Word |
| Автоматический перевод | Claude Code или Codex CLI и аккаунт с подходящей подпиской |

Внешние программы устанавливаются отдельно. Подписка нужна только для автоматического перевода.

Работа приложения проверена на Windows и Mac с Apple M1. Для Mac Intel доступны сборки, но пользовательская проверка ещё предстоит. Открытие PDF проверено в Adobe Acrobat; переходы по относительным ссылкам после переноса папки — в SumatraPDF на Windows. В Acrobat такие переходы после переноса требуют отдельной проверки. **В PDF24 Reader относительные ссылки могут не работать.**

## Первый комплект

1. Создайте проект и добавьте PDF. При необходимости загрузите основной DOCX с уже существующими сносками.
2. Задайте номера, имена и оформление приложений. Выберите страницы или фрагменты, при необходимости подготовьте перевод.
3. Проверьте результат и подтвердите подготовку документов.
4. В «Ссылки в Word» сопоставьте упоминания с приложениями и проверьте границы ссылок.
5. В «Проверка и экспорт» устраните ошибки, подготовьте основной PDF и скачайте ZIP.
6. Распакуйте весь комплект и проверьте документы и переходы по ссылкам.

Начать можно со встроенного учебного комплекта. [Подробная инструкция](docs/PILOT.md) описывает перевод, учебный пример и проверку результата.

## Данные и приватность

Исходные файлы сохраняются отдельно. Проекты хранятся на вашем компьютере: `%USERPROFILE%\.bl-exhibit-manager` на Windows и `~/.bl-exhibit-manager` на Mac. Для резервной копии остановите приложение и скопируйте папку проектов целиком.

При переводе провайдеру отправляется только показанный и разрешённый вами текст. Сам PDF не отправляется. Авторизация выполняется через официальный CLI Claude или Codex; API-ключи не требуются. Облачной синхронизации и телеметрии нет.

Не прикладывайте конфиденциальные документы, токены или папку проектов к публичным Issues. Для сообщения об ошибке используйте вымышленный пример и укажите версию приложения, ОС и шаги воспроизведения.

## Ограничения

- Входные форматы: PDF для приложений и переводов, DOCX для основного документа. До 50 МБ на файл и 1000 страниц на PDF.
- OCR и автоматический перевод сканов, печатей и изображений не поддерживаются. Можно прикрепить готовый перевод PDF.
- До 120 000 выбранных знаков за один перевод; одновременно выполняется один перевод. Правки черновика нужно подтвердить и прикрепить заново, чтобы они попали в комплект.
- Сноски для перевода размечаются вручную. Сложные таблицы, оформление надстрочных знаков и переходы к сноскам автоматически не восстанавливаются.
- Выделенные прямоугольные фрагменты становятся изображениями и теряют поиск по тексту.
- Защищённые PDF, формы и цифровые подписи, DOCX Strict, макросы и некоторые сложные элементы сносок не поддерживаются.
- Очень большие комплекты могут потребовать значительного объёма памяти.
